Проект: Простой сайт на Django

Описание:
Данный проект реализует простой веб-сайт с одной страницей, которая возвращает приветственное сообщение.

Как запустить:
1. Установите Django: pip install django
2. Перейдите в папку проекта
3. Запустите сервер: python manage.py runserver
4. Перейдите на http://127.0.0.1:8000/
